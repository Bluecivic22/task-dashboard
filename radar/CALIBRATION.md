# Calibration Guide

## Workflow
1. Name the deployment and confirm room dimensions.
2. Draw the perimeter and major obstacles.
3. Place node coordinates accurately.
4. Record an **empty-room baseline** for at least 30 seconds.
5. Walk the perimeter slowly to expose edge response.
6. Mark calibration points where motion should be detected reliably.
7. Review baseline variance and node agreement.
8. Save calibration and re-check confidence.

## Placement Tips
- Use diagonally separated nodes when possible.
- Keep nodes clear of HVAC vents and moving blinds.
- Re-run baseline after moving furniture or changing antenna orientation.

## Quality Assessment
Good calibration typically shows:
- low empty-room variance
- consistent baseline RSSI per node
- strong confidence near calibration path
- limited false positives from fans or appliances

## Re-Calibration
Re-calibrate after:
- furniture rearrangement
- new access points / channel changes
- firmware updates impacting filtering
- persistent environmental change state alerts
